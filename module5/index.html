Introduction

Concurrency is one of the biggest strengths of Go (GoLang). It allows a program to handle multiple tasks efficiently while keeping the code simple and readable.

1. What is Concurrency?

Concurrency means handling multiple tasks during the same period of time.

Example:
  • Boiling Rice
  • Making Tea
  • Frying Vegetables

While one task waits, you continue working on another task.

2. Concurrency vs Parallelism

Concurrency Parallelism
Managing many tasks. Executing many tasks simultaneously.
Works even on one CPU core. Needs multiple CPU cores.
Focuses on task management. Focuses on simultaneous execution.

3. What is a Goroutine?

A Goroutine is a lightweight thread managed by the Go Runtime.

  • Very small memory usage
  • Fast to create
  • Can create thousands or millions

4. Go Scheduler

The Go Scheduler decides which Goroutine runs and when.

Think of it like a Traffic Police Officer controlling vehicles at an intersection.

9. Race Condition

Occurs when multiple Goroutines modify shared data simultaneously. 


Counter = 0

Worker A -> Reads 0

Worker B -> Reads 0

Worker A -> Writes 1

Worker B -> Writes 1

Expected = 2

Actual = 1

10. Mutex

Mutex allows only one Goroutine to access shared data at a time.

Think of a room with only one key. Only one person can enter at a time.
